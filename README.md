🎙️ Telugu Speech-to-Text

    A simple web application that converts **spoken Telugu** into **text** using the browser's **Speech Recognition API**.

🌟 Features
- Real-time speech recognition in **Telugu**  
- Instantly displays transcribed text  
- Copy transcribed text to clipboard with a click  
- Fully **frontend** — no backend or server required  
- Responsive and user-friendly UI

💻 How to Use
1. Open the live site: [Live Demo](https://haripriya-explorer.github.io/telugu-speech-to-text/)  
2. Click the **microphone icon** to start speaking in Telugu  
3. Your speech will appear as text in real time  
4. Click the **Copy** button to copy the text

🛠️ Technologies Used
- **HTML**  
- **CSS**  
- **JavaScript**  
- **Web Speech API** (for speech recognition)
  
⚠️ Notes
- Works best on **Google Chrome**  
- Ensure **microphone access** is allowed in your browser
